# Aethelgard.

## A Mad Libs word game in Python: you give the words, it writes the adventure.

## Aethelgard is a sci-fi fantasy MMORPG where trapped players must level up and hack the game's source code to escape.

## How to run the story:

- python mad_libs.py

## What I practiced
- input()
- Cleaning answers with `.strip()`, `.title()` and `.lower()`
- Math with variables (`{number * 2}`)
- Shouting a word with `.upper()`
- Multi-line f-strings with triple quotes `"""`
- Clean answer with: .strip() .title() and .lower() 
- Counting words with `len()` and `.split()`
